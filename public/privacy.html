Privacy Policy

Udini Periodic Table • Last Updated: November 5, 2026

1. Introduction & Application Overview

This Privacy Policy explains how Udini Periodic Table ("we", "our", or "the Application"), accessible at https://periodictableassignment.vercel.app, collects, uses, stores, and protects Google user data when you sign in using Google OAuth 2.0 (Google Identity Services). Udini Periodic Table is an interactive 3D data visualization web application that renders structured dataset records into four 3D spatial layouts (Table, Sphere, Double Helix, and Grid).

2. Data Collection (Google User Data We Access)

When you authenticate with Google Sign-In, the Application requests basic, non-sensitive OpenID Connect scopes (openid, email, and profile). Through the Google Identity Services JSON Web Token (JWT) credential returned to your browser, the Application temporarily receives access to:

  • Your basic Google profile information (name and profile picture URL).
  • Your Google Account email address and unique Google user identifier.
  • Authentication token metadata used to confirm a valid login session.

3. Data Usage (How We Use Google User Data)

We use the Google user data accessed via Google Sign-In strictly for the following limited purposes:

  • User Authentication: To verify that you are an authenticated Google user before unlocking and rendering the interactive 3D Periodic Table visualization interface.
  • Session Control: To transition the user interface from the sign-in screen to the 3D visualization scene within your active browser tab.

We do not use Google user data for advertising, marketing, user profiling, analytics tracking, or training artificial intelligence/machine learning models.

4. Data Storage, Retention & Protection

  • No Backend Storage or Persistence: Udini Periodic Table is a purely client-side static web application. We do not operate any backend database, and we do not store, log, or retain your Google profile data, email address, or authentication tokens on any server.
  • Ephemeral In-Memory Processing: The authentication response is processed transiently in your browser's memory and is immediately discarded when you refresh or close the browser tab.
  • Security & Encryption: All network traffic between your browser, Google Identity Services, and our hosting provider (Vercel) is encrypted in transit using industry-standard HTTPS / TLS protocols.

5. Data Sharing & Disclosure to Third Parties

We do not sell, rent, trade, transfer, or disclose your Google user data or personal information to any third parties. Google user data is never shared with external analytics providers, advertisers, or data brokers.

6. Limited Use Compliance

Udini Periodic Table's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. User Rights, Data Deletion & Revoking Access

Because we do not store any personal or Google user data on external servers, there is no stored personal data to delete upon request. You may revoke Udini Periodic Table's permission to access your Google Account at any time by visiting your Google Account Security & Permissions page.
